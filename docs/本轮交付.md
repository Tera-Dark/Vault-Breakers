# 节目演出、社交与轻量荣誉｜本轮交付

本轮按「一局的节目感 → 等候区参与 → 荣誉与纯外观」落地，未改变奖池、报价算法或 Heat 的评价依据。

**工程：**[VaultBreakers.rbxl](../VaultBreakers.rbxl)。打开后 Play，菜单仍默认收起。

> **验收状态：源码/规则/入口契约及工程一致性已检查；原生验收仍待进行。** 此环境没有 Roblox Studio。以下功能已接入实际服务器/客户端，不是浏览器原型；但自动化使用 Roblox doubles，不能证明原生灯光、碰撞、头像加载、音频权限/听感或真实 DataStore 行为。不要直接以此替代发布前验收。

## 1. 一局的演出链路

| 环节 | 已实现 | 保持的边界 |
|---|---|---|
| 主舞台亮相 | 2 秒 SHOWTIME、红毯/入口落点、选手头像与名字、短机位推镜；选手可跳过 | Quick 不播放；不脚本代走；CLAIM 的 45 秒从过场结束/跳过后开始 |
| 小奖排除 | 按奖池档位识别 1–50 CR，短金色光效、14 片本地彩带、欢呼 | 排除不发 Credits，也不增加决策分 |
| 大奖排除 | 顶端两档 5,000/10,000 CR：短暂抽空音乐、吸气/低频重击、舞台局部红色脉冲 | 没有高频全屏闪烁或剧烈震屏；不会波及 Quick 的镜头/声音 |
| 报价 | 1 秒 OFFER_ROLL，单调递增且不超过真实报价，机械滴答、落定重音 | 服务器先确定报价；数字定格后才开始完整 18 秒；滚动期间不能决策 |
| 最后两门 | 压低本场环境灯，两个门位聚光与选手补光 | 保留基础可读性，不更改全局 Lighting；另一场继续运行 |
| 地面引导 | 合法金库的脉冲环、附近门的描边；最终门口支持 KEEP/SWAP | 光圈不处理 Touched；必须用 E、触摸或 R2 确认；UI 选择仍保留 |

新的完整主线为：

```text
MAIN: SHOWTIME → CLAIM
QUICK:          CLAIM
                  ↓
BREACH → OPENING → BREACH_REACT → 下一次 BREACH / OFFER_ROLL
                                                 ↓ 数字落定
                                            OFFER（18 秒）
                                                 ↓ PUSH
                                     TRANSITION → 下一轮 / FINAL_CHOICE
EXTRACT / KEEP / SWAP → REVEAL → RESULT → IDLE
```

Main 的排除反应窗口为 1 秒，Quick 为 0.45 秒；它们不会把已经排除的金额当成奖励。减少动态效果会关闭彩带/动态色脉冲和切镜，并直接显示最终报价。

## 2. Green Room 社交

- **实况电视：**休息室中央墙面新增 32×14 studs 大屏，以 SurfaceGui 展示选手、轮次、报价、剩余时间、剩余奖池、最近排除与 Quick 状态。报价与 HUD 使用同一服务器时间轴。
- **这是公开赛况播报，不是第二份完整舞台视频。**`BroadcastState` 明确列出可传播字段，未开的金额映射和个人投票不会混入大厅广播。
- **快捷反应：**四个固定短句；每人 4 秒冷却、同一舞台最多 3 条在 2.6 秒窗口内显示。舞台上浮动气泡显示发言者；不给刷表情奖励，不替代投票，不允许自由文本。
- **主动入座：**12 张沙发座位增加 E/R2 提示。只有主动使用提示才请求导演机位；意外碰到座位不会抢镜。起身/跳离/参赛/角色离场可恢复；设置可关闭入座机位。
- 反应面板可单独关闭，不把新的常驻大面板塞回游戏；排队和主菜单逻辑保持独立。

## 3. 声音配置与来源

- 新增 Music / SFX / Crowd / UI 分组，重要事件时音乐让位；最后五秒低频脉冲逐渐加速。
- 靠近电视时场景声音可从电视位置播放；Quick 选手优先听自己的舞台。音乐、观众声、减少动态效果可分别设置。
- `AssetConfig.Sounds` 已配置 **7 个不同的 Creator Store 合作方音频 ID**，覆盖门锁、门、低频冲击/脉冲、欢呼、吸气、悬疑音乐和节目结尾。Click/Tick 仍有内置提示音。
- 已核对 Roblox 公开 API 返回的类型、发布者和分发标记，详情见 [音频来源清单](../art/audio/library-manifest.json)。**未在目标体验实播或试听，不能承诺权限、剪辑位置或听感已经通过。**默认吸气素材为单人吸气，不冒充已经完成的整场人群录音混音；低频心跳默认采用合成脉冲。
- 另外提供 **9 个原创 WAV**，含新增 8 秒悬疑脉冲、亮相和低频冲击。所有原文件均无第三方采样。上传后填 `AssetConfig.OriginalUploads`，不要覆盖合作方后备表；失效上传会尝试回退至库素材。
- 音频预载不阻塞开局，迟到的一次性声效不会在错误阶段补播。`StudioChecks.run()` 现在也报告音频加载状态；Loaded 不是听感验收。

## 4. 荣誉与纯外观

### 本服名人堂

三个展台使用本服真实完成对局的最高**基础奖励**排序，异步加载角色模型；限制尺寸/零件量，固定并移除脚本、碰撞与无关效果。加载失败保留占位与提示，旧请求不能覆盖新上榜玩家。

### 四个头衔

| 头衔 | 条件 | 是否奖励运气/改变 Heat |
|---|---|---|
| 两门之间 | 完成最终 KEEP/SWAP | 仅经历收藏 |
| 就这一块 | 最终金库基础金额 1 CR（即使倍率后支付 2 CR） | 仅运气记录，不改 Heat |
| 从容离场 | 完成的对局中累计 3 次正向评价 EXTRACT | 根据当时信息 |
| 有据可进 | 完成的对局中累计 3 次正向评价 PUSH | 不计自动选择，不奖励盲目拒绝大报价 |

头衔从「纪录 → 头衔与金库涂装」装备，显示在人物附近；亮相也显示本局头衔。

### 手轮涂装

原钢免费；黄铜 500、冰蓝 1,200、紫釉 2,400 **虚拟 Credits**。购买先确认、服务端定价、重复请求不重复扣费；临时只读档案不能解锁。已拥有的外观可装备，下局生效，不改变当前对局参数或金库的功能色。没有 Robux、随机箱、付费概率或新货币。

### 历史榜：已做可选实现，默认关闭

`HistoryConfig.Enabled=false`。启用后仅汇总真实完成的基础奖励，以 OrderedDataStore 的 max 更新；写入合并、读缓存、失败重试。缓存失效明确标记，完全读不到时退回**本服**，不把本服数据伪装成历史排名。

先在独立测试体验验证预算/冲突/失败路径，再决定启用。历史同分由后端排序返回，不承诺全服同分顺序稳定。

## 5. 档案迁移与上线门槛

- 档案升级为 **v3**，新增外观所有权、装备、头衔与分类型正向决策计数。
- 旧余额、声望、Heat、最佳值和原始根字段保留。旧版缺少可分辨的决策历史，因此不会凭旧奖金追认头衔。
- 新增深复制，避免保存中的外观集合被后续购买改写；高于/不兼容当前版本的档案进入临时模式，不降级覆盖。
- **切换时停止旧写入服务器，备份真实数据。旧 SetAsync 版本和旧 v2 规范化逻辑都不应与 v3 混写。**回滚必须先准备兼容 v3 的读写逻辑，不能直接换回旧包。

## 6. 实际执行的验证

- 47 个生产 Luau 文件编译（非静态类型检查）。
- 21 组原规则（含 1,000 次确定性完整模拟）+ 10 组演出/进度纯逻辑 + 7 组客户端状态。
- 16 组入口/布局 + 17 组生命周期边界 + 9 组菜单 + 16 组节目/社交/成长入口契约。
- **合计 96 组回归通过。**包含过场死亡、过期输入、同服重连、只读档案、保存中解锁、旧头像请求、反应限流、机位退出与单场音效隔离。
- 工程反向解码：61 个节点、47 个嵌入源码与工作区一致。
- 9 个原创 WAV 格式、长度、峰值、哈希通过；7 个库资产的配置/清单一致。

基础场景 2,729 BaseParts、12 Seats、26 Light 对象（包含默认关闭的聚光灯）。菜单 205 个本地零件；名人堂每座最多 55 个角色零件；彩带每场最多 14 片。这是预算，不是实测帧率。

**仍未验证：**原生 place 打开、灯光材质/字体、人物行走与碰撞、真实三客户端复制、触屏/手柄、音频权限与听感、真实 DataStore。按 [Studio QA](STUDIO_QA.md) 完成这些项目后，才进入 6–8 人试玩及发布判断。
